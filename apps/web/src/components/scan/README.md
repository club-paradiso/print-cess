# Scanner UI

The scanner treats a captured image as a document rather than merely embedding the photograph in a PDF.

Each imported page is automatically analyzed for a four-corner paper boundary. The corrected preview shows the perspective-flattened result and whether the boundary detector was confident. Users can open **Adjust edges** to drag each corner, re-run automatic detection, and choose Auto clean, Color, Grayscale, or Black & white processing. Rotation and page ordering remain non-destructive until PDF generation.
